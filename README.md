# Java Programming Fundamentals

An introductory repository based on core concepts from the IBM Developer Java learning path. This guide covers object-oriented programming (OOP) fundamentals, Java syntax, memory management principles, and hands-on exercises designed to build production-ready code habits.

---

## 📌 Prerequisites

Before running the code in this repository, ensure you have the following installed on your environment:

- **Java Development Kit (JDK):** Version 17 or higher (OpenJDK or IBM Semeru Runtime recommended)
- **IDE:** Eclipse IDE for Java Developers, VS Code, or IntelliJ IDEA
- **Build Tool (Optional):** Apache Maven 3.8+ or Gradle

Verify your Java installation via your terminal:
```bash
java -version
javac -version
